# App screenshots

Drop real Senzz screenshots here with these exact file names. Each one replaces its
"Screenshot placeholder" automatically on the next build. Portrait phone captures
(about 1080 × 2400) work best; PNG or WebP under ~400 KB each keeps the site fast.

| File                 | Where it shows                   | What to capture                                  |
|----------------------|----------------------------------|--------------------------------------------------|
| `home.png`           | Home hero (behind)               | App Home screen (credits + features)             |
| `suggest.png`        | Home hero (front) + Suggest      | Keyboard with the Suggest panel and 3 replies    |
| `enhance.png`        | Enhance section                  | Keyboard with the Enhance result                 |
| `fumble.png`         | Fumble Protection section        | Keyboard showing a "Possible fumble" warning     |
| `privacy.png`        | Privacy section                  | Onboarding "Your privacy matters." screen        |
| `setup.png`          | Setup section                    | Onboarding "Turn on Senzz Keyboard" screen       |
| `delete-account.png` | /delete-account                  | Settings › Data controls                         |

Using WebP or another name? Change the `shot="…"` value in `src/pages/index.astro`
or `src/pages/delete-account.astro`.
